LATEX SOURCES FOR THE EIGHT NEW CAMPAIGN CLOSURES
=================================================

Prepared: September 2, 2026

Contents
--------

L2_publication_note.tex
  Literal counterexample at the omitted parameter a = 0.  This does not
  settle the source-intended nonzero-parameter statement.

L3_publication_note.tex
  Counterexample to the positive CMC index--area bound in a complete,
  noncompact, positively curved ambient three-manifold.  A closed-ambient
  repair remains open.

L9_publication_note.tex
  Proof of the generic integer-order W-congruence statement in the fixed-order,
  real-analytic, nondegenerate stratum, with the real-sign qualification stated
  explicitly.

L10_publication_note.tex
  Proof of the noninteger-order A-infinity statement in the fixed-order,
  real-analytic, nondegenerate W-congruence stratum.

L30_publication_note.tex
  Literal counterexample using a nonintegral stationary varifold.  The
  source-intended integral-varifold conjecture remains open.

L38_publication_note.tex
  All-dimensional argument that all sufficiently large Steklov indices have
  finite critical length.  The note preserves its independent-audit caveat.

L41_publication_note.tex
  Explicit cut-open annular-sector construction proving a positive exterior
  Robin threshold for a bounded, nonconvex, simply connected Lipschitz
  hyperbolic obstacle.  The note preserves its independent-audit caveat.

M5_round_sphere_pwidth_counterexample.tex
  Counterexample to the proposed round-sphere p-width formula.

Compilation
-----------

Each file is standalone and compiles with:

  latexmk -pdf -interaction=nonstopmode -halt-on-error FILE.tex

All author fields are placeholders.  Replace the author, affiliation, and any
submission metadata before circulation.  The source/status qualifications in
each note are part of the mathematical claim and should not be removed without
an additional literature and proof audit.
